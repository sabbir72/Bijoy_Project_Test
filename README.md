Web Application Automation – Bijoy Project

 Project Overview

This project demonstrates end-to-end web application automation using **Python**, **Pytest**, and **Playwright**. The automation framework focuses on validating post-login business workflows through a scalable, reusable, and maintainable test architecture.

The project follows QA automation best practices, including reusable fixtures, centralized configuration management, structured test organization, and detailed test execution.

---

## 🎯 Project Objectives

- Automate critical post-login user workflows.
- Validate core application functionality.
- Build a maintainable automation framework.
- Improve regression testing efficiency.
- Practice professional QA automation standards.
